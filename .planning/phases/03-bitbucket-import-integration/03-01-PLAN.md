## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| FastAPI→PostgreSQL→Redis | Durable authority is committed before a UUID-only task crosses the queue boundary. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-03-02 | Tampering | logical import concurrency | high | mitigate | Product/mapping/import locks and execution-identity conditional writes prevent duplicate starts and stale completion. |
| T-03-03 | Information disclosure | public schemas/browser state | high | mitigate | Closed Pydantic/generated schemas and recursive forbidden-field tests exclude source bytes, provider bodies, secrets, unsafe URLs, and internals. |
