<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser cookie/Origin -> auth mutations | Ambient credentials and caller-controlled origin request rotation or revocation. |
| Concurrent requests -> PostgreSQL session family | Multiple actors race to consume one refresh authority. |
| Password-change input -> global user authority | A credential mutation invalidates all access and refresh authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Spoofing | refresh replay | high | mitigate | Hashed opaque tokens, conditional/locked rotation, one successor, family revocation on replay. |
| T-05-02 | Spoofing | cookie-authenticated CSRF | high | mitigate | SameSite/HttpOnly/Secure settings plus exact Origin rejection before mutation. |
| T-05-03 | Elevation of Privilege | password-change token purpose | high | mitigate | Purpose-aware principal dependency allows only the change endpoint. |
| T-05-04 | Tampering | password/session transaction | high | mitigate | Single database transaction and rejection-state invariants. |
| T-05-05 | Denial of Service | rotation/password hashing | medium | mitigate | Per-session/user Redis limits before costly work, fail closed for sensitive endpoints. |
</threat_model>
