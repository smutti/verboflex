# Quick task 260907-px2 plan

## Goal

Expose one automatic, server-authoritative import experience: a truthful three-step progress indicator while polling, a consolidated warnings view (including duplicate-key summaries and details), and a direct imported-strings view filtered to the current product.

## Assumptions

- Progress represents the durable states already exposed by the import API: request queued, repository files processing, and terminal results. It must not claim an invented percentage inside the worker's `running` state.
- Warning data is derived automatically from parser issues and duplicate-report summaries already returned by the backend.
- The existing Translations workspace remains the canonical imported-string view; the import screen deep-links to it with the current product filter instead of creating a second search implementation.
- Imports are still explicitly started by the authorized user; “automatico” applies to polling, status transitions, warning discovery, and product-filter propagation.
