# Administrator service status visual hierarchy

Administrators now see service health immediately below the Workspace heading, before identity and administration summaries. The dashboard derives one explicit overall state using `unavailable > pending > online`, then presents API, database, Redis, and worker as individual service cards.

The presentation uses the existing success, warning, and destructive color tokens together with distinct icons and visible text labels, so color is supplemental rather than the only status signal. Loading and unreachable-API states use the same prominent surface and retain the existing sanitized retry behavior. Non-administrator roles keep the compact status presentation.
