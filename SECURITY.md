# Security

VerboFlex is pre-1.0. Security fixes target the current `main` branch; no older
release has a separate maintenance commitment.

Report vulnerabilities through the repository's **Security → Report a vulnerability**
option when enabled. If it is unavailable, open an issue requesting a private
contact without describing the vulnerability. Do not post exploits, credentials,
private localization data or database dumps in a public issue.

Include the affected revision, deployment setup, impact and a minimal reproduction
using synthetic data. Review dependency advisories and apply updates before exposing
an installation. Deployment operators remain responsible for HTTPS, credentials,
backups, access control and monitoring.
